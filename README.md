# 可比公司智能筛选与合理性分析助手

**Comparable Company Screening and Analysis Assistant** 是面向可比公司法估值审计工作的 AI 辅助决策系统。它帮助团队建立候选池、执行透明的结构化筛选、比较业务信息、定位客户名单差异，并为人工确认后的公司生成带差异分析的初稿。系统不自动完成审计结论。

## 项目背景

可比公司法估值的可靠性，很大程度上取决于可比公司的选择是否合理。处于同一行业并不代表两家公司具有可比性，还需要综合判断主营业务、产品与应用场景、客户群体、商业模式、经营规模、成长性、盈利能力和资本结构等因素。如果候选公司选择不当，即使后续估值倍数计算准确，最终估值结果也可能产生较大偏差。

实际分析中，候选公司数量较多、资料来源和字段口径不统一，逐家公司阅读、比较和记录判断依据需要投入大量时间。客户提供的可比公司名单也需要独立复核，既不能因为公司已在名单中就默认纳入，也不能只给出结论而缺少可追溯的分析理由。因此，需要一套能够连接候选池构建、规则筛选、业务可比性分析、人工确认和估值计算的完整流程。

本项目以每家被投企业为单位建立候选池，通过结构化规则和 AI 辅助分析比较企业之间的相似点与重大差异，再由人工决定最终纳入或排除。经确认的可比公司将直接用于估值倍数统计和股权价值测算，同时保留分析依据、复核状态和关键计算过程。系统的目标是提高分析效率和一致性，让可比公司选择及估值结论更透明、更容易复核，而不是替代专业人员作出最终判断。

## 系统架构

- `app.py`：Streamlit 五步交互页面。
- `src/data_loader.py`：工作簿读取、字段检查与数据质量汇总。
- `src/rule_filter.py`：可配置规则和 IQR 估值倍数异常识别。
- `src/scoring.py`：透明的加权得分计算。
- `src/llm_client.py`：可替换的 OpenAI 风格 Chat Completions adapter；未配置 API 时使用标识清楚的本地演示规则。
- `src/prompt_templates.py`、`src/models.py`：证据约束提示词和 JSON 输出模型。
- `src/candidate_pool.py`：按被投企业独立建池、逐级扩池并合并客户指定关系。
- `src/comparison.py`：根据候选关系生成规则任务及客户名单差异分类。
- `src/export_service.py`：格式化 Excel 导出。
- `src/workpaper_filler.py`：按人工确认的工作簿、工作表和单元格定位，将合理性分析写入上传底稿的副本。
- `src/valuation.py`：计算可比公司企业价值、估值倍数、统计区间及被投企业股权价值。
- `sample_data/demo_input.xlsx`：完全虚构的演示工作簿（2 家被投企业、每家 12 家候选公司及客户名单）。
- `sample_data/demo_workpaper.xlsx`：虚构的底稿模板，可演示按单元格回填。

## AI 与人工职责

**程序负责：**读取 Excel、数据清洗、数值计算、规则筛选、IQR 异常识别、加权得分、排序、差异分类、导出，以及后续底稿回填所需的 `workpaper_file`、`sheet_name`、`cell_address` 字段预留。

**AI 负责：**从给定文本提取业务信息、比较语义、总结相似点和差异、标记信息不足与风险、提供分析初稿。每个业务结论要求引用输入资料。模型不能从记忆补充企业事实。

**人工负责：**确定筛选标准与权重、评估差异的估值影响、处理边界案例、确认最终纳入或排除、复核 AI 输出并对审计结论负责。模型输出不是审计结论。

## 安装和启动

建议使用 Python 3.11。

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
streamlit run app.py
```

Windows 用户也可以双击 `启动应用.bat`。保持弹出的命令窗口运行，然后访问 `http://localhost:8501`；关闭该窗口或按 `Ctrl+C` 会停止网页。

未配置模型密钥仍可启动并使用规则筛选、完整页面流程、排名和虚构演示输出。模型调用使用环境变量：

```powershell
$env:LLM_API_KEY="你的授权密钥"
$env:LLM_BASE_URL="https://api.openai.com/v1"
$env:LLM_MODEL="支持 JSON 输出的模型名"
streamlit run app.py
```

也可复制 `.env.example` 为 `.env` 并由你自己的启动环境加载；应用不在代码中保存密钥。请勿提交 `.env`。

## 输入 Excel 格式

Excel 文件包含三个工作表：`investee`、`candidates`、`client_list`。列名用下方英文标识。上传后页面报告缺列和空值；空值会提示风险，默认不直接排除。

| 工作表 | 必需字段 |
| --- | --- |
| investee | `company_id`, `company_name`, `industry`, `company_description`, `main_business`, `products`, `application_scenarios`, `customer_groups`, `business_model`, `revenue`, `total_assets`, `revenue_growth`, `gross_margin`, `ebitda_margin` |
| candidates | 与被投企业相同的业务和经营字段（`company_id` 可选），另可含 `stock_code`, `market`, `market_cap`, `valuation_multiple`, `valuation_multiple_type`, `source_reference`；资本结构可用 `debt_to_assets` 或 `total_liabilities` |
| client_list | `investee_company_name`, `comparable_company_name` |

估值倍数可用字段 `valuation_multiple` 提供，程序按 IQR 标记明显异常值；需要至少 4 个有效倍数才识别。财务单位及增长率/利润率口径应在一个工作簿内保持一致。可选底稿定位列为 `workpaper_file`, `sheet_name`, `cell_address`。上传表中的其他文本列和数值列也可在规则页添加为自定义定性或定量维度的数据来源。

## 页面使用流程

1. **数据上传与质量检查：**载入工作簿或选择虚构样例，查看缺失字段及数据预览。
2. **独立建池、定量规则与分组权重：**系统优先为每家被投企业匹配同细分行业公司；数量不足时，仅在数据提供行业大类或邻近/上下游字段时逐级扩池，再合并该企业对应的客户名单。同一被投企业与候选公司组合自动去重，不生成全局笛卡尔积。候选仍不足时提示人工补充，但不阻断后续流程。随后可在侧边栏调整收入规模、总资产、增速和利润率阈值，并配置定性/定量维度及权重。
3. **AI 相似度与候选排名：**AI 对通过当前规则的候选配对进行业务比较，同时保留客户已选但未通过规则的配对供重点复核。候选来源和扩池理由只作为分析背景，不直接作为可比性证据，也不增加第四步或最终Excel的输出字段。所有有效配对集中显示在任务大表中；点击表格行查看维度得分、证据、差异、资料充分性、建议和客户名单差异。演示模式输出明确标注为简单文本启发式，不是实际模型分析。
4. **人工确认：**任务大表分列显示两家公司原始资料、AI 连贯的可比性原因分析、可追溯证据、人工复核状态/意见和人工最终决定。人工可填写意见后要求 AI 重生成单条回复，也可直接修改合理性分析。只有“已复核 + 纳入”的配对才进入最终可比公司名单和后续估值。
5. **估值分析与导出：**直接复用第一次上传的数据和第四步“已复核 + 纳入”的最终可比公司。页面先设置适用于全部企业的估值方案，默认采用 EV/EBITDA 及 P25、P50、P75；估值方法支持多选，也可通过分子/分母新增自定义方法，倍数支持自定义分位点和手工输入。控制权溢价、流动性折价及其他企业价值或股权价值调整均可配置。计算完成后先展示全部被投企业总览，再点击企业查看基础数据、可比公司倍数和价值桥接明细。导出副本会增加估值调整项、估值计算过程及汇总工作表，不要求再次上传 Excel。

页面提供标准 Excel 模板下载。对于 Wind、东方财富或其他自定义表头，可在第一次上传时选择工作表并完成字段映射。估值可选字段包括 `market_cap`、`cash`、`interest_bearing_debt`、`minority_interest`、`preferred_stock`、`non_operating_investments`、`ebitda`、`net_profit`、`book_equity`、`reporting_period`、`valuation_date`、`currency` 和 `amount_unit`。企业价值桥接使用有息负债，不以总负债替代。

页面按原始需求分为数据检查、规则筛选、候选排名和人工确认四个功能区。规则筛选和人工复核页面均提供全量配对任务大表；候选排名可按被投企业、AI 建议和关键词筛选，点击某一行即可查看各维度评分、相似点、差异、证据，并排查看被投企业与候选公司资料，避免逐家切换下拉框。

## 评分与规则

评分分为定性和定量两组，维度、权重均可在页面新增、删除和调整。定量默认包括收入/资产规模、收入增长率、毛利率、EBITDA 利润率和资本结构（资产负债率）；资产负债率可直接读 `debt_to_assets`，也可根据 `total_liabilities / total_assets` 计算。定性默认包括行业匹配、主营业务、产品及应用场景、客户群体和商业模式；新增维度时可选一个或多个已有文本列作为 AI 比较依据。程序根据配置确定性计算定量相似度；AI 只输出有输入证据支持的定性评分。未知或缺失维度不按 0 分处理，显示资料覆盖率，并在组内对有值维度归一化。演示模式的定性评分只使用简单文本启发式；真实模型评分仍须人工核验。评分、阈值和建议仅用于辅助排序，不能替代审计判断。

估值倍数异常值使用 IQR 的 1.5 倍区间标记；样本不足时不判断。规模默认范围、差异容忍度及行业规则都可在侧栏修改。

## 评估指标

可用历史人工确认名单衡量 Top 5/Top 10 候选召回率、AI 建议人工采纳率、客户名单差异发现率、证据可追溯率、单家筛选耗时、人工阅读候选数量、合理性初稿平均修改次数。错误纳入率与错误排除率不能仅靠历史最终名单计算：最终名单只含正样本，还需补充当时的完整候选池、被排除公司及排除原因。建议按行业分层抽样，并由独立复核人标注基准答案。

示例公司与数值均为虚构，不含真实客户资料。请只使用获得授权的数据和模型，并在发送资料至模型前遵守组织的数据处理要求。不要上传或提交 API Key、密码、Token 或内部接口地址。所有 AI 输出必须经过人工复核；产品仅提供审计辅助信息，不自动确定可比公司，也不宣称自动完成审计。
